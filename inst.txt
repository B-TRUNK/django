To start an app and a view:
===========================
#to start any app inside the project (eg. home/contact/about/pages!)
1 - python3 manage.py startapp pages
2 - head to settings.py -> undet INSTALLED_APPS -> 'pages.apps.PagesConfig',
3 - head to urls.py, add : from django.urls import path, include,
4 - in same file under urlpatterns add : path('mypages/' ,include('pages.urls')),
5 - goto apps folder created and create a new file calle urls.py.

#you will not be able to navigate to the new url unless you set a view
1 - goto pages -> views -> from django.http import HttpResponse
2 - add a function to a new view with HttpResponse (def index(request):
    return HttpResponse('Hello, Visitor'))
3 - add this new function to the urls under pages app
4 - add this to pages/urls.py :
    from django.urls import path
    from . import views

    urlpatterns = [

        path('' ,views.index ,name='index')

    ]

#Working with templates
=======================

1 - create a folder named 'templates' on project root folder.
2 - head to settings.py and import os
3 - in settings.py under TEMPLATES ,inside 'DIRS'[] add : os.path.join(BASE_DIR, 'templates')
4 - create a template for your vies functions
5 - modify yout views to call the render function instead of HttpResponse

====================================================================================

#Working with static files
==========================

1 - goto main project folder (contains settings) and create a folder named 'static'
2 - config under STATIC in settings.py :
STATIC_ROOT = os.path.join(BASE_DIR ,'static')
STATICFILES_DIRS = [
    os.path.join(BASE_DIR ,'bsq/static'),
    ]
3 - run python3 manage.py collectstatic ,now a folder called static
should be shown in project root
4 - use it in your html pages
